# Чат (Slack)

[![hexlet-check](https://github.com/Daewoow/react-urfu-project-12/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/Daewoow/react-urfu-project-12/actions)

Учебное real-time приложение на React с REST API и WebSocket.

## Установка

```bash
npm install
```

## Разработка

Запустите сервер:

```bash
make start
```

В другом терминале запустите Vite:

```bash
npm run dev
```

## Сборка и production-запуск

```bash
make build
make start
```

Сервер будет доступен по адресу: <http://localhost:5001>.

## Демо

Ссылка на приложение в Render: <http://192.168.3.4:5001/>
